# Менеджмент разработки программного обеспечения

Учебные практические работы по дисциплине. Преподаватель — Сюсин Илья Александрович. Все работы посвящены одному сквозному проекту.

## Что выбрали

**Автоматизация подтверждения заказов через онлайн-оплату в веб-приложении продажи металлопроката** для условной компании ООО «МеталлСнаб».

- **Сейчас:** покупатель оформляет заказ → менеджер звонит и вручную переводит заказ в обработку → оплата при доставке через терминал или наличными.
- **После доработки:** покупатель оформляет заказ и оплачивает его через СБП → приложение проверяет подтверждение платежа и автоматически переводит заказ в обработку.

Дорабатываем существующее приложение: подключаем одного платёжного провайдера и автоматизируем подтверждение заказа. Каталог, отображение статусов, комплектация и доставка уже существуют. Конкретный провайдер пока не выбран.

## Как пользоваться

1. Начните с устава в PDF и контекста в `AGENTS.md`. Файлы можно скачать через GitHub или клонировать репозиторий:

   ```bash
   git clone https://github.com/darik-cell/01-susin.git
   ```

2. Для правок откройте DOCX в Microsoft Word или LibreOffice; после изменения обновите соответствующий PDF.
3. Следующие работы размещайте в `lab-XX/`, исходные задания — в `lab-XX/zad/`. Используйте тот же проект и сохраняйте согласованность документов.
4. Предложения и изменения отправляйте через Issues или pull request на GitHub.

Каталог `.ai` исключён из Git и не публикуется.
